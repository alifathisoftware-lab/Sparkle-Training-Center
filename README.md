# Sparkle Training Center

مشروع الموقع الكامل، ويشمل نسخة المصدر ونسخة جاهزة للفتح في المتصفح.

## المعاينة السريعة

افتح `dist/index.html` مباشرة.

## تعديل وبناء المشروع

```powershell
npm install
npm run build
```

- ملفات التطوير: `src/`
- النسخة الجاهزة: `dist/`
- الصور: `dist/assets/`
- جدول Vue وAnt Design Vue: `src/schedule.js`

المواعيد وبيانات التواصل من المواد المرفقة، ويجب تأكيدها مع إدارة المركز قبل النشر النهائي.
